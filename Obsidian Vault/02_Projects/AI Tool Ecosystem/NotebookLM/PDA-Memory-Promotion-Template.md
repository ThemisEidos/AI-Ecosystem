## Promotion Criteria

- [ ] The insight is reusable
- [ ] The insight is sanitized
- [ ] The insight is not a secret or restricted detail
- [ ] The insight helps future work
- [ ] The insight is not tied to a one-off private context

## Obsidian to PDA Memory Flow

1. Capture the NotebookLM output in Obsidian.
2. Distill it into a concise reusable statement.
3. Check that it is still Category 1.
4. Record it in PDA memory with source linkage.
5. Reuse it in prompts, reports, and future planning.
