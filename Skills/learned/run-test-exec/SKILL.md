## When to use
Use this skill when you need to run a PowerShell script, specifically for testing execution and validation of script functionality.

## Procedure
1. Open your PowerShell environment.
2. Navigate to the directory where the `Test-Exec.ps1` script is located.
3. Execute the script by typing `.	est-exec.ps1` and pressing Enter.
4. Monitor the output for success confirmation, which should indicate `[Test-Exec.ps1 — OK]`.
5. Check the COOPER Workbench execution status to ensure it reports `-- OK`.
6. Note the timestamp and host information for your records.
