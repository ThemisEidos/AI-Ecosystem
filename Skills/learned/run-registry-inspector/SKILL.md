## When to use
Use this skill when you need to review the current status and configuration of tools available in the Open Workshop environment.

## Procedure
1. Initiate the Registry Inspector tool by running the command: `run registry inspector`.
2. The tool will provide a summary of the operational status of the tools in the registry, including their levels and whether they are set to auto-run.
3. Review the list of tools, which includes their names, categories, and any approval requirements for certain actions.
4. Use the information to make informed decisions about tool usage, imports, promotions, or research tasks.
