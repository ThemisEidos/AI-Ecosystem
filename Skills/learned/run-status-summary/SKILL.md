## When to use
Use this skill when you need a quick overview of the current operational status, especially in a workshop or project setting.

## Procedure
1. Initiate the request by stating "run a status summary".
2. The system will generate a summary that includes the operational status and any relevant timestamps.
3. Review the summary for clarity and completeness, ensuring it reflects the current state of operations.
