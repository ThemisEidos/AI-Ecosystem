## When to use
Use this skill to create concise summary reports for project updates, ensuring all key points and next actions are clearly communicated.

## Procedure
1. **Identify Main Point:** Determine the primary outcome or conclusion of the review or project phase.
2. **Gather Supporting Details:** List any relevant details that support the main point, such as completed tasks, issues resolved, or changes made.
3. **Define Next Action:** Specify what needs to happen next, including any monitoring or follow-up actions required.
4. **Format the Report:** Structure the report with a clear title, main point, supporting details, and next action for easy readability.
