## When to use
Use this skill when you need to run the pda_command_router workflow with a specific test payload from a batch, ensuring that the workflow processes the data correctly.

## Procedure
1. Identify the batch number and the specific payload you want to test. In this case, it is batch 5.
2. Prepare the test payload that corresponds to the identified batch.
3. Execute the pda_command_router workflow using the command: `/reporter test payload from batch 5`.
4. Monitor the execution for any errors or issues.
5. Review the results to ensure the workflow has processed the payload as expected.
