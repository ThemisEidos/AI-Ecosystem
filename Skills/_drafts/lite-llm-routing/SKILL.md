## When to use
Use this skill when you want to efficiently route prompts to different models using the LiteLLM Router tool.

## Procedure
1. **Initiate the LiteLLM Router**: Start by accessing the LiteLLM Router tool in your environment.
2. **Prepare your prompt**: Write the prompt you want to send to the model. For example, "say the word banana".
3. **Route the prompt**: Use the LiteLLM Router to send your prompt to the appropriate model. This can be done by specifying the model you want to use, such as OpenAI.
4. **Receive the response**: After routing, wait for the model to process the prompt and return a response. For instance, the model might respond with "Banana! 🍌".
5. **Utilize the output**: Use the output from the model as needed in your application or workflow.
