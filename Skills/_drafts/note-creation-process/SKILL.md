## When to use
Use this skill when you want to create a new note in the Obsidian Knowledge Shelf, ensuring that the note is properly formatted and stored.

## Procedure
1. Identify the title of the note you want to create (e.g., 'batch4-test.md').
2. Prepare the content of the note, ensuring it serves its intended purpose (e.g., proving the note_editor executor works end to end).
3. Use the appropriate command or interface to create the note in the Obsidian Knowledge Shelf.
4. Confirm that the note has been created successfully by checking the inbox or designated storage location.
